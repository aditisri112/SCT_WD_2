# ⏱️ Aesthetic Stopwatch

A modern and user-friendly stopwatch web application built using HTML, CSS, and JavaScript. The application allows users to accurately measure time intervals with start, pause, reset, and lap recording functionalities.

## Features

* Start and pause the stopwatch
* Reset the timer to zero
* Record and display lap times
* Clean and aesthetic pastel-themed user interface
* Responsive and easy-to-use design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project files.
2. Open the `index.html` file in any web browser.
3. Use the buttons to start, pause, reset, and record lap times.

## Project Objective

This project was developed as part of a web development internship task to demonstrate DOM manipulation, event handling, and interactive UI design using core web technologies.
